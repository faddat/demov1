What’s powered by the SDK?+

NUNCHI SDK

Signed, retrievable evidence.

Crypto + Common: original Rust primitives provide demo identities, transaction encoding, signing and verification.

Oracle: actual AppendRecord, apply_transaction, record and namespace/writer queries write and retrieve events through an app-provided memory store.

RPC is not needed or used in this local example.

WHAT THE APPLICATION HANDLES

The organization and accounting.

Workflows, synthetic usage collection, token counts, pricing, customers, budgets, alerts, pause/resume, billing calculations and visualization.

Every usage event is synthetic, then genuinely signed and recorded. No provider or model service is called.

WHY IT MATTERS

A charge you can trace.

Developers can connect their own usage source to this recording pattern and build accounting, billing and monitoring around it.

Signatures authenticate the signed message and detect edits. They do not prove external usage, correct prices or a valid invoice.

Simulation Assumptions & SDK Details+

Integration & provenance

SDK 2026.9.0-alpha.1, pinned commit eea35ced709f68c15d6fbc8bcc754696a7e44374. Original Crypto, Common and Oracle sources are shared unchanged with Robotics Lab. Browser manifests and a Common adapter disable native QMDB.

Twenty public deterministic software keys. Fresh session namespace and independent writer nonces on every restart. All displayed SDK operations execute newly in local WebAssembly; no captured evidence is substituted.

SDK modules ↗ · Pinned source ↗

Accounting assumptions

Input tokens × input USD-per-million ÷ 1,000,000, plus output on the same basis, plus tool calls × USD per invocation. Components round once to microUSD; totals sum those integers before display rounding.

Cost per completed workflow includes all usage, even unfinished work. Retry charges are a subset, not extra charges. A tool event can contain several invocations. Example rates are editable and versioned in each payload.

The synthetic period is one hour. Eight-hour projections extrapolate the observed rate and are not forecasts or measured ROI.

Application policies & limits

Budgets warn at 80%; they do not enforce stops. A repeating agent is flagged at 60 tool calls in five simulated minutes. Detection and workflow pause are app logic.

Local memory clears on refresh/restart. No persistent QMDB, state-root proof, validators, RPC, consensus, external usage attestation or native AI budget enforcement is deployed. A session ends at one hour or 1,024 usage events.

Export replay verifies included messages and arithmetic, not snapshot completeness or the truth of usage.
